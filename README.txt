Wardrobe V2

این نسخه یک PWA استاتیک و بدون API است.
فایل index.html را روی هر هاست استاتیک مثل Netlify Drop منتشر کنید.

ویژگی‌ها:
- افزودن لباس با عکس
- ذخیره محلی در مرورگر
- دسته‌بندی، Fit، رنگ، فصل و موقعیت
- فیلتر کمد
- پیشنهاد ست با امتیاز هماهنگی
- Service Worker برای PWA

نکته: چون عکس‌ها در localStorage ذخیره می‌شوند، برای نسخه حرفه‌ای بعدی بهتر است IndexedDB اضافه شود.
